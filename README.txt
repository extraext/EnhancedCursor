==================================================
EnhancedCursor v1.3.0 for Kerbal Space Program
==================================================

FEATURES:
- Smooth right-click panning and cursor centering
- Idle cursor auto-hide during flight
- Customizable cursor highlight halo
- Full UI settings window (AppLauncher button)

INSTALLATION:
1. Open the .zip file.
2. Drag and drop the "GameData" folder directly into your main KSP directory.
3. Ensure the final path is: KSP/GameData/EnhancedCursor

COMPATIBILITY:
- Built for KSP 1.12.x
- Compatible with Camera & First-Person mods
